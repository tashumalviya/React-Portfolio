# 🚀 React Portfolio

A modern, responsive developer portfolio built with **React**, **Vite**, and **Tailwind CSS**. The portfolio features a macOS-inspired interface, smooth animations, interactive components, and a clean user experience to showcase projects, skills, and achievements.

## ✨ Features

* 💻 Modern macOS-inspired UI
* ⚡ Built with React + Vite
* 🎨 Responsive design for all devices
* 🌙 Clean and elegant dark theme
* 🚀 Smooth animations and transitions
* 📂 Interactive project showcase
* 👨‍💻 About, Skills, Experience & Contact sections
* 📄 Resume download support
* 📱 Mobile-friendly layout
* 🔥 Fast performance and optimized build

## 🛠️ Tech Stack

**Frontend**

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)

**Libraries**

* GSAP
* Framer Motion
* Lucide React
* React Icons

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/tashumalviya/React-Portfolio.git
```

### Navigate to the project

```bash
cd React-Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
